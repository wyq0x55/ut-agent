# 确定性测试规则引擎与 Pipeline 架构

规则引擎接收来自 `tooling/ut-clang-extract` 提取的 Typed FunctionIR，并结合 `ResolvedTestPolicy`（Base TestBaseline + Requirement Modules + ProjectRulePack），执行确定性 8 阶段生成流水线：

```text
Typed FunctionIR + ResolvedTestPolicy
                 │
                 ▼
          1. Obligation Builder  (C0/C1/MC-DC/Boundary/Entry)
                 │
                 ▼
          2. Constraint Builder  (Typed Domain Constraints)
                 │
                 ▼
          3. Deterministic Solver (Witness Generation)
                 │
                 ▼
          4. Semantic Evaluator  (C Post-State Calculation)
                 │
                 ▼
          5. Oracle Builder      (Caller-visible Expected Effects)
                 │
                 ▼
          6. Validator           (Domain & Branch Enforcement)
                 │
                 ▼
          7. Suite Builder       (Deduplication & Intent Packaging)
                 │
                 ▼
          8. Target Projection   (WinAMS TestCsv / Harness / DefineVar)
```

正式 API 位于 `src/ut_agent/generation` 与 `src/ut_agent/project`：

```python
# ResolvedTestPolicy 组合式策略
policy = resolve_test_policy(manifest, registry)

# 确定性 8 阶段生成
suite = generate_semantic_suite(function_ir, policy)

# WinAMS 目标投影
winams_artifacts = project_winams(suite, winams_config)
```

`ResolvedTestPolicy` 必须携带锁定版本的 Base `TestBaseline`（如 `psd-rebuild-v1.6`）与叠加的需求模块（如 `mcdc`）。只有当用例校验通过且没有 `UNSAT` / `NEEDS_REVIEW` 错误时，生成的 `TestSuite` 才能进入 WinAMS 目标投影。

正常生成（`ut-agent gen`）完全只依赖源码、配置与已审批策略包。历史 Golden TestCsv **绝对禁止**在正常生成主链路中读取；Golden 仅被 `learning` 模块用于离线对比、Gap 分析与规则推导。

---

## 8 阶段生成门禁

1. **Obligation**: 针对每个控制节点与值域生成明确测试观点。MC/DC 要求为每个可达原子条件生成独立影响组合成对用例。
2. **Constraint**: 将 Obligation 转换为强类型约束集合。
3. **Solve**: 求解器在类型化值域内为约束求取唯一的确定性代表 witness。
4. **Evaluate**: `SemanticEvaluator` 根据 UUT 源码语义计算内部变量修改与 post-state。
5. **Oracle**: 从 post-state 提取 Caller-visible 的预期效果（返回值、全局变量后置状态、Stub 捕获与输出）。
6. **Validate**: 强力校验 Witness 输入与 Oracle 完整性。缺失 Expected Effect 或非法状态的用例标记为 `NEEDS_REVIEW` / `UNSUPPORTED`，不会泄露为默认零值。
7. **Suite**: 组装与去重，保留独立测试观点。
8. **Target Projection**: 将语义 Suite 投影为 WinAMS CSV/Harness/DefineVar 产物。

## 规则包与审批工作流

项目专属规则包 (`ProjectRulePack`) 格式为 UTF-8 JSON：

```json
{
  "name": "N-O2608-PSD-087-rules",
  "version": 1,
  "rules": [
    {
      "id": "project.N-O2608-PSD-087.scenarios",
      "status": "approved",
      "scope": {"function": "Target_Func"},
      "match": {"kind": "scenario_matrix"},
      "action": {"input_columns": [], "output_columns": [], "scenarios": []},
      "priority": 10,
      "evidence": ["sha256:...", "review note"],
      "approval": {"authority": "reviewer", "reason": "人工用例语义确认"}
    }
  ]
}
```

通用生成逻辑严禁在代码中写 `if project_id == ...`。所有的项目差异均通过 `ProjectRulePack` 声明与审批。
